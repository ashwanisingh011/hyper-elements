# NOTES & DECISION LOG: Northwind Summit Launch Kit

## 1. Library Discovery & API Findings

### Package Selection: `@hyper-elements/react` vs `@unlayer/react-elements`
- The modern official package for Hyper Elements is `@hyper-elements/react` (published by Unlayer, latest v0.4.5).
- Package includes built-in AI agent documentation: `GUIDE.md` and `REFERENCE.md`.
- Components and syntax differences from legacy Unlayer Elements:
  - **No props for styles:** Styles are passed strictly via `style={{ ... }}`, never as direct props.
  - **No margins:** Spacing between siblings is controlled by the parent container's `gap` prop in `style` (e.g. `<Column style={{ gap: 16 }}>`), and internal spacing is `padding`.
  - **Layout Primitives:** `Section` (full-bleed background band), `Row` (side-by-side flex layout with `stackOnMobile`), `Column` (vertical stack, cards when styled with background and border), `Grid` (equal-width columns, stacks on mobile).
  - **Text Primitives:** `Heading` (`level={1..6}`), `Text`, `Span`, `Link`, `LineBreak`, `MergeTag`. No raw HTML (`<b>`, `<br>`).
  - **Roots:** Exactly 4 root components: `<Page>` (web), `<Email>` (responsive email-safe HTML + plain text), `<Document>` (paged print document), `<Canvas>` (fixed-dimension canvas e.g. 1200x630).
  - **Theming:** Central theme tokens (`midnight` default and `daylight` alternative) power all 4 templates.
  - **Render API:** `render(element)` returns `{ html, text, diagnostics }`. Errors throw `ElementsError`.
